# Music

The site has a small music player (top right). This file explains how it works
and how to add your own songs.

## What ships

Three short ambient tracks generated by `scripts/make_demo_tracks.py` (original,
no samples, free to reuse). They exist so the player works on day one. Replace
them with your own whenever you like.

To regenerate them (needs Python 3 and numpy; MP3 output needs `ffmpeg`):

```bash
python3 scripts/make_demo_tracks.py
```

## Add your own song

1. Convert it to a small file: MP3 or AAC, 96 to 128 kbps, **under 4 MB**.

   ```bash
   ffmpeg -i your-song.wav -codec:a libmp3lame -b:a 128k public/music/your-song.mp3
   ```

2. Put the file in `public/music/`.
3. Add an entry to `public/music/library.json`:

   ```json
   {
     "title": "Song title",
     "artist": "Artist name",
     "file": "your-song.mp3",
     "startAt": 10,
     "license": "Who owns it and under what terms, e.g. 'Mine, all rights reserved'",
     "sourceUrl": "https://link-to-the-source-or-license"
   }
   ```

   - `startAt` is in seconds. Leave it at `10`, or use `0`. If a song is shorter
     than 10 seconds it starts at 0 automatically.
   - `license` is shown in the player card, so credit it honestly. If you use
     someone else's track, you need their permission or an open license (for
     example Creative Commons) and must give the credit it asks for.
   - `sourceUrl` is optional; if present it shows as a "source" link.

4. Commit and push. Remove the demo entries (and their `.mp3` files) if you no
   longer want them.

Order in `library.json` is the order in the player. Titles and artists come from
this file, not from the audio file's tags.

## How playback behaves

- Browsers block sound until the visitor interacts. **Enter with sound** on the
  first screen is that interaction; **Enter silent** keeps the music off.
- The choice, last song, volume and mute state are remembered in the visitor's
  browser (localStorage). On later visits the music starts on their first click,
  tap or key press, never before.
- Every song starts at its `startAt`, fades in over about 2 seconds, loops back
  to `startAt` when it ends, and fades out over about 1 second when the song
  changes, the music is switched off, or the tab is hidden.
- Volume and fades use the Web Audio API (a gain node), because iOS Safari
  ignores `audio.volume`.
- A fade-out during a page refresh is best effort: the browser can stop the page
  before it finishes. The next load always fades in.
- There are no YouTube or Spotify embeds.

## Heads up: public repos

Audio files committed to a public repository can be downloaded by anyone, and
so can the site's `public/music` folder once it is live. Only commit songs you
are happy to have copied. If a track must not be downloadable, do not put it in
this repo.
